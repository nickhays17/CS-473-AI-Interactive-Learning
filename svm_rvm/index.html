17.3.5 · Turning SVM scores into probabilities

An SVM outputs a raw score f(x) = wᵀx + b (or its kernel version), not a probability. Platt scaling fits a 1-D logistic regression on top of that score:

p(y=1 | x) = σ( A·f(x) + B )

A and B are fit by minimising the NLL. Crucially they should be fit on held-out data (or cross-validated scores): on the training set the SVM pushes points to f ≈ ±1 or beyond, so the scores look over-confident and the fit is biased. Below, the dots are held-out scores (blue = y=+1, orange = y=−1); dashed lines are the margins f=±1.

Try: set A=1, B=0 (just a sigmoid on raw f) and note the NLL. Press Fit. B≠0 shifts the 50% point away from f=0 (corrects class imbalance / bias), A rescales how fast confidence grows with margin.

17.3.6 · SVM vs logistic regression: it’s the loss

With labels ỹ ∈ {−1,+1} and margin m = ỹ·f(x), both are L2-regularised linear (or kernel) models; only the loss differs:

hinge: ℓ(m) = max(0, 1 − m) (SVM, with C = 1/λ) logistic: ℓ(m) = log₂(1 + e^(−m)) (logistic regression) 0-1: ℓ(m) = 1[m < 0] (what we actually care about)

Both are convex upper bounds on 0-1 loss. The key difference: the hinge is exactly zero for m ≥ 1, so well-classified points have zero gradient → the solution depends only on support vectors (sparse in the dual). Logistic loss is never exactly zero, so every point has a (tiny) say and the dual is dense — but it gives calibrated probabilities for free.

Try: slide m beyond 1. Hinge value and gradient both hit 0 (that point is not a support vector); logistic still has a small non-zero gradient. Slide m below 0 and both penalise roughly linearly (robust to outliers, unlike squared/exponential loss).

17.3.7 · Multiclass SVMs

SVMs are inherently binary, so we combine binary classifiers. One-vs-rest (OvR) trains C classifiers f_c (class c vs the rest) and either takes the sign pattern or argmax f_c. One-vs-one (OvO) trains C(C−1)/2 pairwise classifiers and takes a majority vote. Problems with OvR: ambiguous regions (none or several f_c > 0), class imbalance (each “rest” class is huge), and the f_c are not calibrated against each other, so argmax can be skewed.

Setup: f_c(x) = s_c·(u_c·x − t), with u_c at 90°, 210°, 330°. In sign-rule mode, raising t opens an “unclaimed” triangle in the middle and lowering it creates overlaps. Argmax removes all ambiguity, but then shrink/grow class 3’s scale: its region swells or collapses even though the hyperplane f_3=0 has not moved. OvO has no ambiguity here but needs C(C−1)/2 models.

17.3.8 · Choosing C (and the kernel width)

In the soft-margin SVM, C = 1/λ trades margin width against slack: small C = strong regularisation (wide margin, many support vectors, underfit); large C = weak regularisation (tight fit, wiggly boundary, overfit). In the dual, 0 ≤ αᵢ ≤ C. C and the RBF width γ (κ = exp(−γ‖x−x′‖²)) are normally chosen by cross-validation over a grid. Here a small separate test set plays the role of validation data. (The solver is a simplified SMO on the dual.)

Try: sweep C from 0.01 up to 1000 and watch the support vectors (ringed points) shrink while the boundary starts to chase individual noisy points. The lower plot sweeps C at the current γ: training error keeps falling, held-out error is U-shaped — pick the bottom. Then change γ: the best C moves too, which is why you grid-search both.

17.4 · Sparse vector machines: the RVM

SVMs are sparse but not probabilistic in a clean way. The relevance vector machine takes a generalised linear model on kernel features φ(x) = [κ(x,x₁),…,κ(x,x_N)] and gives each weight its own Gaussian prior (automatic relevance determination):

p(y|x,w) = N(y | wᵀφ(x), 1/β), p(wⱼ) = N(0, 1/αⱼ) Fit αⱼ, β by maximising the marginal likelihood (evidence): Σ = (diag(α) + βΦᵀΦ)⁻¹, μ = βΣΦᵀy γⱼ = 1 − αⱼΣⱼⱼ, αⱼ ← γⱼ/μⱼ², β ← (N − Σγⱼ)/‖y − Φμ‖²

Many αⱼ → ∞, which pins wⱼ=0 and prunes that basis function. Survivors are the relevance vectors. Unlike SVM support vectors they tend not to sit near the decision boundary, you get predictive variance, and the model is usually much sparser — at the cost of a non-convex objective and O(N³) training. Compare with ridge regression on the same kernel features: all N weights stay non-zero.
