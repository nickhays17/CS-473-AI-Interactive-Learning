What you’re looking at

Each dot has two features: horizontal position (the x-view) and vertical position (the y-view). Two classes are mixed together, so no single feature separates them perfectly. The shaded background is the current model’s best guess for each region.

Only the big outlined dots have labels. Everything else starts grey. Each Step lets the model label some grey points itself, which are called pseudo-labels, and retrain on them.

Things to try

  • Set labeled points to 1 and compare all three methods after a few steps. Supervised-only barely moves; the others can improve.
  • Run self-training for many rounds and watch the red × marks. A wrong pseudo-label becomes training data and can pull the boundary the wrong way.
  • In co-training, raise the view correlation to about 0.9. Both views now see nearly the same thing, so they can’t correct each other and the advantage shrinks.

Why co-training works

Co-training assumes each example has two views that are each enough to learn from and are roughly independent given the class. A point that sits in the ambiguous middle of the x-view may be clearly class 1 in the y-view. The y-view model labels it confidently and passes it to the x-view model, which learns something it could not have worked out alone. Each model keeps supplying the other with examples it finds hard. The purple ring marks points labeled by the x-view model, and the green ring marks points labeled by the y-view model.
