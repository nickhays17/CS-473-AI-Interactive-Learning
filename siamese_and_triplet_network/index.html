Siamese and triplet networks

Instead of asking “which class is this?”, these networks learn an embedding space where similar things sit close together and different things sit far apart. Drag the points below and watch the loss respond.

The idea

A Siamese network runs two inputs through the same encoder (identical architecture, identical weights). Each input becomes an embedding vector, and the distance between the two embeddings says how similar the inputs are. It trains on pairs labeled “same” or “different”.

What to notice

  • Similar pairs are always pulled together: the loss grows with the square of the distance.
  • Dissimilar pairs are pushed apart only until they are m away. Past the margin the loss is exactly 0, so the network stops wasting effort on pairs that are already separated.
  • Without a margin, the network could cheat by pushing everything infinitely far apart, or collapse everything to one point.
  • At test time you embed two new inputs and compare their distance to a threshold. This works for classes never seen in training, which is why Siamese networks are used for face verification and signature matching.

The idea

A triplet network uses three inputs through one shared encoder: an anchor, a positive (same class as the anchor) and a negative (different class). Instead of judging pairs in isolation, it compares them directly: the positive should be closer to the anchor than the negative, by at least a margin.

Easy, semi-hard, hard

Easy

d(a,n) > d(a,p) + m. Loss is 0 and the triplet teaches the network nothing.

Semi-hard

d(a,p) < d(a,n) < d(a,p) + m. Ordering is right but the gap is too small. These are the most useful for training.

Hard

d(a,n) < d(a,p). The negative is closer than the positive. Big loss, but too many of these early can destabilize training.

Pairs versus triplets

  • Contrastive loss judges each pair against an absolute scale: same pairs should have distance near 0, different pairs beyond m.
  • Triplet loss only cares about relative distance for each anchor, so classes can be loose clusters of different sizes as long as the ordering holds.
  • With N examples there are O(N³) possible triplets and most are easy, so practical training relies on triplet mining: choose semi-hard or hard negatives within each batch.
  • Embeddings are often L2-normalized so the margin has a consistent meaning.
