Manifold learning: unrolling the Swiss roll

High-dimensional data often lives on a low-dimensional sheet that is bent through space. The points below are a flat 2D sheet rolled up in 3D. Can an algorithm recover the flat sheet using only the points? Color shows position along the sheet, so you can see whether neighbors stay neighbors.

The manifold idea

The data has 3 coordinates, but only 2 numbers are needed to say where a point is: how far along the roll, and how far across. The roll is a 2D manifold sitting in 3D space.

Why straight lines fail

Two points on neighboring layers are close in 3D yet far apart along the sheet. PCA only sees the 3D distance, so it flattens the roll like a shadow and the layers overlap.

How Isomap fixes it

Link each point to its k nearest neighbors, then measure distance by hopping along those links. That approximates travel along the sheet. Then place points in 2D so those distances are preserved.
