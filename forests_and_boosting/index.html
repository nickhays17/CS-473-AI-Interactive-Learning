Random forests and boosting, side by side

Both methods combine many small decision trees into one strong model. They differ in how the trees are made: a forest grows them independently and averages them, boosting grows them one after another, each fixing the last one’s mistakes.

Grow many trees, then average

Each tree trains on a random resample of the data and, optionally, looks at only one random feature per split. Alone, a deep tree memorizes its sample and gives jagged borders. Averaged, the quirks cancel out.

Out-of-bag accuracy scores each training point using only trees that never saw it, a free test estimate.

Dot size shows the current weight of each point. Big dots are the ones the ensemble keeps getting wrong, so the next tree is pushed to focus on them.

Add trees one at a time

Boosting starts with a very simple tree, then reweights the data to emphasize its mistakes and trains the next tree on that. Each tree gets a vote proportional to how accurate it was.
